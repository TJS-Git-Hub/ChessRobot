# v2.3.0-vision-offline-rc.1

日期：2026-11-05。状态：**CONDITIONAL，离线候选版**。默认观察，不默认启用真实机械臂。这是软件验证里程碑，不是“实机稳定版”或“任意场景 100% 识别版”。历史标签不重写，本说明记录当前版本的验收边界。

## 本版内容

- 默认识别保持 RTMPose + 原始 SwinV2 Nano + 保守后处理，MobileNetV3 有限辅助；没有重训或更换权重。
- 高清预览、原图小坐标引线和中文侧栏；新帧外观复核、温和阴影与小幅相机抖动容忍，手部独立检查。
- 统一 10×9 盘面、a0～i9、FEN、14 通道张量和观测元数据；张量顺序为 `krncbapKRNCBAP`，与现有游戏 AI 一致。
- 走棋/吃子提议、规则验证、ACK 后提交；合法中残局显式初始化；拒绝非法走棋时不更新已提交基准。
- 圆心质量检查、毫米偏置和新鲜度；支持显式非均匀格距、可选镜头/棋子高度修正。缺失或不可信偏置不会变成零补偿。
- 动作令牌和动作完成后的帧号/采集时间屏障；全盘及目标圆心复核通过后才提交机器人走法，失败停止，不自动额外纠偏。
- 图片/视频/相机无机器人诊断、CLI 观察/模拟入口、GUI 启动与退出处理；第三代观察回退保留，未满足新协议的旧接口不开放自动硬件模式。

## 实际验证

2026-11-05 本机执行 `tools/verify_vision_offline.py`：**180 PASS，0 FAIL，0 ERROR，0 SKIP**。测试禁止数字编号相机和 CH347 访问；5 个本地 ONNX 均实际加载并完成有限数值前向检查。

其中包含生产状态机、重复/过期帧、遮挡恢复、推理异常、事务提交、普通移动/吃子、动作失败、错盘/超差、连续五轮 Fake Camera/Recognizer/Robot 集成，以及文件输入和 Qt offscreen 入口测试。模拟不是实物精度验证。

一张人工复核的非对称开发照片上，90 格真值回归通过，重复 12 次一致；独立照片数为 1，不能称为 12 张盲测。64 个合成圆心用例均通过；同一实拍图的圆心 27/32 有效、5 个明确拒绝，没有真实毫米误差真值。强反光仍有限制，不宣称所有光照或局面的近 100%。

复现命令（在项目根目录，日志位于项目外）：

```powershell
$visionVersionCheck = Join-Path $env:USERPROFILE ('.codex\cache\tasks\chessrobot-version-check-' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
python -B tools/verify_vision_offline.py --output-dir $visionVersionCheck
python -B main.py --mode simulate
```

ONNX、用户照片和手部模型不在此 Git 版本中，换电脑需单独准备；缺少本地图片时部分测试会明确跳过，不能复述本机的“0 SKIP”。详细命令、相机选择和标定流程见 [启动与验收手册](../vision-readiness.zh-CN.md)。
